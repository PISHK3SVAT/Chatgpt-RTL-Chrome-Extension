# ChatGPT RTL

Every day, I kept running into the same little problem while using ChatGPT in Persian.

Some elements wouldn't render the way I wanted, so I'd open DevTools, inspect the element, and manually change its `dir` attribute to `rtl`... again and again. 😅

So I decided to **automate this repetitive task** and turned it into a simple Chrome extension.

Now, instead of opening DevTools every time, I just let the extension do it for me. :)

**Small problem. Simple solution. One less repetitive task.**
